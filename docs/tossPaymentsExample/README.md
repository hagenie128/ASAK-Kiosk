# SCAC 간편결제 직접 연동 테스트

팀 배포 및 향후 백엔드 구현에 필요한 상세 설명은 [GUIDE.md](./GUIDE.md)를 참고하세요.

결제위젯 서비스 신청 없이 간편결제를 테스트하는 키오스크용 React 앱입니다. 토스페이와 카카오페이는 API 개별 연동으로 호출하고, 네이버페이는 차후 백엔드 연동을 위한 QR 샘플 화면을 제공합니다.

## 결제 흐름

```text
토스페이·카카오페이:
SCAC 대형 버튼 → 공식 결제창 → 서버 승인 → 결과 화면

네이버페이:
SCAC 대형 버튼 → 샘플 QR → 모바일 연결 안내 화면
```

계좌이체는 UI와 결제 요청에서 제외되어 있습니다.

## 네이버페이 QR 샘플

네이버페이 버튼을 선택하고 결제하기를 누르면 실제로 스캔 가능한 QR이 표시됩니다. QR에는 현재 아래 형태의 임시 모바일 URL이 들어갑니다.

```text
http://키오스크주소:5173/mobile-pay?sessionId=DEMO-...&method=naverpay&amount=1000
```

스캔하면 백엔드 연동 예정 안내 화면이 열리며 실제 결제는 발생하지 않습니다. 차후 `sessionId`를 백엔드가 발급하도록 교체하고 모바일 화면에서 네이버페이를 호출하면 됩니다.

휴대전화 테스트 시 `.env`에 휴대전화가 접근할 수 있는 주소를 설정하세요.

```env
VITE_PUBLIC_ORIGIN=http://키오스크_LAN_IP:5173
```

## 환경변수

`.env.example`을 `.env`로 복사하고 토스페이먼츠 개발자센터의 `API 개발 연동 키` 한 쌍을 입력합니다.

```env
VITE_TOSS_CLIENT_KEY=test_ck_로_시작하는_API_개별_테스트_클라이언트_키
TOSS_SECRET_KEY=test_sk_로_시작하는_매칭_테스트_시크릿_키
```

`test_gck_` 결제위젯 키는 사용할 수 없습니다. 시크릿 키는 서버에서만 사용되며 React 코드로 전달되지 않습니다.

## 실행

```powershell
cd C:\project\SCAC\qr-payment-test
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

## 테스트 조건

- 토스페이와 네이버페이는 개발 연동 테스트 상점 키로 테스트할 수 있습니다.
- 카카오페이는 계약 이후 발급받은 상점 테스트 키가 필요할 수 있습니다.
- 테스트 키로 승인된 결제는 실제 금액이 출금되지 않습니다.

## 운영 전 보완

- 현재 서버는 주문을 메모리에 저장하므로 재시작하면 진행 중 주문이 사라집니다.
- 운영 환경에서는 DB 또는 Redis, HTTPS, 사용자 인증, 결제 로그 및 웹훅 검증을 적용해야 합니다.
